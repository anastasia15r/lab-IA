# Лабораторная работа №1

## Тема

Реализация конечного автомата для распознавания формальных языков

---

## 1. Цель работы

Целью лабораторной работы является разработка детерминированного конечного автомата для распознавания слов заданного формального языка и его программная реализация на языке C#.

В ходе работы необходимо реализовать последовательный анализ входной строки, определить её принадлежность заданному языку и проверить работу программы на корректных и некорректных входных данных.

---

## 2. Постановка задачи

Для индивидуального варианта задан формальный язык:
15. `(abcd)ⁿ(ef)ᵐ`, n ≥ 1, m ≥ 1

Это означает, что корректное слово должно состоять из одного или нескольких повторений блока `abcd`, после которых следуют одно или несколько повторений блока `ef`.

Общий вид допустимого слова:

```text
abcdabcd...abcdefef...
```

где:

- $n$ — количество повторений блока `abcd`;
- $m$ — количество повторений блока `ef`;
- $n \geq 1$;
- $m \geq 1$.

Таким образом, блок `abcd` и блок `ef` должны присутствовать в слове хотя бы один раз.

### Примеры корректных слов

| Слово | $n$ | $m$ | Результат |
|---|---:|---:|---|
| `abcdef` | 1 | 1 | Корректное |
| `abcdabcdef` | 2 | 1 | Корректное |
| `abcdefef` | 1 | 2 | Корректное |
| `abcdabcdefef` | 2 | 2 | Корректное |
| `abcdabcdabcdefefef` | 3 | 3 | Корректное |


### Примеры некорректных слов

| Слово | Причина | Результат |
|---|---|---|
| `abcd` | отсутствует блок `ef` | Некорректное |
| `ef` | отсутствует блок `abcd` | Некорректное |
| `abc` | незавершённый блок `abcd` | Некорректное |
| `abcdefabcd` | после `ef` снова появился `abcd` | Некорректное |
| `abceef` | нарушена последовательность `abcd` | Некорректное |
| `abcdefe` | незавершённый блок `ef` | Некорректное |
| `abcdefg` | присутствует недопустимый символ | Некорректное |

---

## 3. Описание конечного автомата

Для распознавания заданного языка используется детерминированный конечный автомат.

Автомат имеет следующие состояния:

| Состояние | Описание |
|---|---|
| `q0` | Начальное состояние |
| `q1` | Получен символ `a` |
| `q2` | Получены символы `ab` |
| `q3` | Получены символы `abc` |
| `q4` | Получен полный блок `abcd` |
| `q5` | Получен символ `e` |
| `q6` | Получен полный блок `ef`, конечное состояние |
| `qError` | Состояние ошибки |

Начальным состоянием является `q0`.

Конечным состоянием является `q6`.

Состояние `qError` используется в случае нарушения заданной последовательности символов.

---

## 4. Логика работы автомата

Для получения первого блока `abcd` автомат должен пройти последовательность:

```text
q0 → q1 → q2 → q3 → q4
```

при чтении символов:

```text
a → b → c → d
```

После получения полного блока `abcd` автомат находится в состоянии `q4`.

Из состояния `q4` возможны два варианта:

1. начать следующий блок `abcd`;
2. перейти к блоку `ef`.

Переходы имеют следующий вид:

```text
q4 --a--> q1
q4 --e--> q5
```

После получения символа `e` автомат переходит в состояние `q5`.

После получения `f`:

```text
q5 --f--> q6
```

автомат переходит в конечное состояние `q6`.

Если требуется несколько повторений блока `ef`, автомат может повторять переходы:

```text
q6 --e--> q5
q5 --f--> q6
```

После перехода к блоку `ef` вернуться к блоку `abcd` уже нельзя.

Например, для слова:

```text
abcdabcdefef
```

последовательность состояний будет следующей:

```text
q0 → q1 → q2 → q3 → q4
   → q1 → q2 → q3 → q4
   → q5 → q6 → q5 → q6
```

Поскольку после обработки всей строки автомат находится в конечном состоянии `q6`, слово принимается.

---

## 5. Схема конечного автомата

Упрощённо работу автомата можно представить следующим образом:

```text
q0 --a--> q1 --b--> q2 --c--> q3 --d--> q4
                                             |
                                        +----+----+
                                        |         |
                                        a         e
                                        |         |
                                        v         v
                                       q1         q5
                                                   |
                                                   f
                                                   |
                                                   v
                                                  q6
                                                   |
                                                   e
                                                   |
                                                   v
                                                  q5
```

Состояние `q6` является принимающим.

При получении неправильного символа автомат переходит в состояние `qError`.

## 7. Программная реализация

Для реализации конечного автомата используется язык программирования **C#**.

Программа считывает введённое пользователем слово и последовательно обрабатывает каждый его символ.

Для каждого символа определяется новое состояние автомата.

Если после обработки всей строки автомат находится в состоянии `q6`, слово считается принадлежащим заданному языку.

Во всех остальных случаях слово считается не принадлежащим языку.

### Алгоритм работы программы

1. Установить начальное состояние `q0`.
2. Получить от пользователя входную строку.
3. Последовательно обработать каждый символ строки.
4. Для каждого символа определить следующее состояние.
5. Если произошёл неправильный переход, перейти в `qError`.
6. После обработки всей строки проверить текущее состояние.
7. Если состояние равно `q6`, вывести сообщение о принадлежности слова языку.
8. В противном случае вывести сообщение о том, что слово не принадлежит языку.
